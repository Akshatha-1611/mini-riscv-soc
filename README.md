# Mini RISC-V SoC

Industry-style RTL SoC project featuring:

- 5-stage pipelined RISC-V CPU
- 2-way set associative cache
- CDC FIFO using Gray code synchronization
- Modular SoC integration

## Planned Architecture

CPU → Cache → CDC FIFO → Memory

- Industry-quality RTL design
- Verification-focused development
- Clean GitHub documentation
- Strong preparation for VLSI/ASIC roles
